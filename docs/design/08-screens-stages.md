# 08 画面・ステージ構成

名称はすべて仮称。

## 1. 画面の一覧と遷移

| 画面 | 内容 | 次の画面 |
|---|---|---|
| 題字 | はじめる、つづきから、設定 | 初回設定、または探索 |
| 初回設定 | 受信の方式（聴／読）、マイクの調整、声の試聴と選択、話す速さ、音声データの同意 | 導入 |
| 導入 | 麓の里での短い物語。実行型の試練で操作と規則を学ぶ | 探索 |
| 探索 | 3D空間を歩く。表示は最小限 | 会話、結び灯籠、稽古場、聴き帳 |
| 会話 | 話し手を映す演出カメラ。字幕は設定次第 | 運ぶ、または応答 |
| 運ぶ | 受け手のところまで歩く | 整理 |
| 整理 | 受け取った内容を札に書き出し、確度の印を付ける | 申し送り |
| 申し送り | 認識結果を確かめて確定する。最後の宣言 | 問い返し |
| 問い返し | 受け手の質問に答える | 判定 |
| 判定 | 成就、未達、歪みの演出 | 分析、または探索 |
| 分析 | 発言と回答の対比。該当箇所の音声の聞き直し | 物言い、探索 |

| 聴き帳 | 記録、弱点、出会った人々 | 探索 |
| 結び灯籠 | 再開地点の登録、稽古場への移動 | 探索 |
| 設定 | 音声、字幕、話す速さ、画質、操作、データの削除 | 元の画面 |

## 2. 主な画面の設計

### 探索

- 画面には何も常時表示しない。灯火は、腰の灯籠の明かりとして人物に付ける。
- 話しかけられる人の近くでは、控えめな印が出る。
- 行き先は地図ではなく、景色の中の目印（鳥居、煙、灯り）で示す。

### 会話

- カメラは話し手の上半身。話し手の視線、手の動き、間を見せる。
- 環境音を下げ、声を際立たせる。
- 表示するのは、聞き返しの操作と、相槌の操作だけ。**残りの間合い、会話の進み具合、重要な箇所の印は表示しない。**
- 評価や助言に当たる表示は一切出さない。
- 字幕は既定で非表示。設定で表示できる。

### 整理

- 和紙の上に札を並べる画面。1文が1枚。
- 札は声でも文字でも作れる。声の場合は認識結果がすぐ札に表示され、直せる。
- 各札に確度の印（聞いた／推し量り／不明）を付ける。印のない札は確定できない。
- 項目の枠は出さない（初級の稽古を除く）。

### 申し送り・問い返し

- 受け手を映す。プレイヤーの札が順に読み上げられる体裁で、確定前に全文を見直せる。
- 最後に「以上ですべてです」か「抜けがあるかもしれません」を選ぶ。
- 問い返しは1問ずつ。答えは「聞いた内容」「聞いていません」「分かりません」のいずれかを、自分の言葉で述べる。選択肢は出さない。

### 判定

| 結果 | 演出 |
|---|---|
| 成就 | 受け手がうなずき、言葉が相手に届く。周囲の霧が薄れ、遠くの景色が見える。静かな鈴の音 |
| 未達 | 受け手が首を横に振り、「それでは渡せぬ」と言う。場面はそのまま。もう一度挑める |
| 歪み | 申し送りの文を順にたどり、歪んだ一文で音が消える。霧が一気に濃くなり、画面が白む。結び灯籠で目覚める |

待ち時間（評価の処理）は、受け手が黙って考える間として見せる。

### 分析

- 左に話し手の発言、右にプレイヤーの文。食い違う箇所に印。
- 発言の箇所を選ぶと、その部分の音声が流れる。
- ミスの種類と、どこで防げたかを短く示す。
- 物言いの入口を置く。

## 3. 地域の構成

5つの地域を順に進む。地域ごとに、主に鍛える能力と、景色・天候・音を変える。

| 順 | 地域 | 景色と天候 | 主に鍛える能力 | 中心となる罠の型 | 試練の型 |
|---|---|---|---|---|---|
| 1 | 麓の里 | 田畑、茅葺きの家、朝もや | 最後まで聞く | 末尾の条件、後出しの訂正 | 実行型が中心。伝達型の導入 |
| 2 | 杉の参道と古社 | 杉木立、苔の石段、濃い霧 | 補完しない、不明を不明と認識する | 欠けた項目、言われていない事柄の質問 | 伝達型 |
| 3 | 渓流の寺 | 渓谷、雨、水音 | 事実と推測の区別 | 話し手の推測、伝聞 | 伝達型、応答型 |
| 4 | 紅葉の峠と関所 | 紅葉、夕暮れ、風 | 矛盾・不足に気づき、確認する | 食い違い、不足、複数の話し手 | 伝達型、応答型 |
| 5 | 霧上の山城 | 雲海、月明かり、静寂 | 総合 | すべて。長い語り、歩きながらの会話、運ぶ途中の更新 | すべて |

### 地域の中身（共通の形）

| 要素 | 数 | 内容 |
|---|---|---|
| 道行き | 3〜4 | 各2〜4個の試練 |
| 結び灯籠 | 道行きごとに1つ、主の試練の直前に1つ | 再開地点 |
| 稽古場 | 1 | 罰なしの練習。その地域の罠の型を選んで試せる |
| 主の試練 | 1 | 複数の段からなる長い会話 |
| 人々 | 8〜12人 | 話し手と受け手。性格と声が異なる |

### 主の試練の例（内容は毎回生成。ここに示すのは型だけ）

| 地域 | 主 | 型 |
|---|---|---|
| 麓の里 | 里の長老 | 長い頼みごとを聞き、言われた通りに里の中で実行する |
| 杉の参道と古社 | 古社の宮司 | 儀式の段取りを聞き、欠けている点を見極めて伝える |
| 渓流の寺 | 寺の住職 | 見たことと聞いたことが混ざった話を、区別して運ぶ |
| 紅葉の峠と関所 | 関所の役人たち | 食い違う複数の証言を聞き、確かめるべき点を確かめて報告する |
| 霧上の山城 | 城の主 | これまでのすべての型を含む長い対話 |

## 4. 空間設計の指針

- **やり直しの移動を短く。** 結び灯籠から最初の試練まで30秒以内。厳しさは会話に置き、移動には置かない。
- **運ぶ距離は意味のある長さに。** 30〜90秒。途中に景色の見どころを置く。
- **会話の場所は静かに、背景は美しく。** 話し手の背後に、その地域の代表的な景色が入る構図にする。
- **霧で視界を区切る。** 描画の負荷を下げつつ、晴れたときの見晴らしを報酬にする。
- **一本道に近い構成。** 迷わせることは目的ではない。寄り道に稽古場や人々の物語を置く。

## 5. 音の設計

| 場面 | 音 |
|---|---|
| 探索 | 環境音が主。音楽はほぼなし |
| 会話 | 環境音を下げる。声だけが近くに聞こえる |
| 運ぶ | 環境音が戻る。上級では他人の話し声が混ざる |
| 成就 | 鈴、風が抜ける音 |
| 歪み | 音が消え、低い響きだけが残る |
| 主の試練 | 低く持続する音で緊張を保つ。会話の妨げにならない音域にする |

会話中の効果音と音楽は、声の聞き取りを妨げない音量と音域に抑える。聞き取れないことは訓練ではなく不公平である。

## 6. 配慮の設定

| 設定 | 内容 |
|---|---|
| 受信の方式 | 聴／読 |
| 字幕 | 表示／非表示 |
| 話す速さ | 0.8〜1.2倍 |
| 回答の入力 | 声／文字 |
| 聞き返しの入力 | 押している間だけ話す／マイクを開いたまま／文字 |
| 画面の揺れ、白む演出 | 弱める／切る |
| 文字の大きさ | 3段階以上 |
| 色に頼らない表示 | 確度の印は色と形の両方で区別する |
