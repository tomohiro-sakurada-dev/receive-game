# 01 ゲームの基本コンセプト

## 1. 一文での定義

**霧に包まれた山国で、人の言葉を聞き、歪めずに運ぶ者となる。聞き終える前に分かったつもりになった瞬間に失敗する、情報受信の修行ゲーム。**

## 2. 鍛える能力と、ゲーム内での現れ方

| 鍛える能力 | ゲーム内で起きること |
|---|---|
| 相手の話を最後まで聞く | 文末や話の終わりで内容が変わる。去り際に呼び止められて追加がある |
| 情報を正確に受け取る | 日時・人物・対象・数量・条件を、そのまま運ぶことが求められる |
| 勝手に情報を補完しない | 言われていないことを訊かれる。正解は「それは聞いていない」 |
| 先読みして結論を出さない | 話が途中で向きを変える。早く切り上げると残りを失う |
| 事実と推測を区別する | 相手自身の推測や伝聞が混ざる。運ぶときに印を付け分ける |
| 矛盾や不足に気づく | 話の中に食い違いや抜けがある。気づいて確かめた者が評価される |
| 不明を不明と認識する | 「分からない」と申告できる。誤って断定するより常に良い |
| 必要に応じて確認する | 会話中に聞き返せる。ただし相手の辛抱には限りがある |
| 話に沿って返答する | 相手が実際に求めたことに答える。想像した求めに答えると失敗する |

最重要の原則は一つである。**情報を受け取り終える前に、自分の解釈を完成させない。** すべての仕組みは、解釈を早く閉じた者が失敗し、開いたまま最後まで聞いた者が成功するように作る。

## 3. これは何のゲームではないか

- **記憶力ゲームではない。** 試すのは「どれだけ多く覚えたか」ではなく「受け取ったものと、自分が足したものを区別できるか」である。量を増やすより、誤って受け取りやすい構造を作ることで難しくする。
- **クイズゲームではない。** 選択肢から選ばせない。選択肢は答えの手がかりになり、受信ではなく照合の力を測ってしまう。プレイヤーは自分の言葉で伝える。
- **戦闘ゲームではない。** 攻撃・防御・弾きは存在しない。緊張は「聞く」ことから生む。

## 4. なぜ面白いのか

見た目ではなく、遊びとしての面白さを次の5つで作る。

1. **聞くことが真剣勝負になる。** 一言の聞き違いで試練が終わる。相手が口を開いた瞬間から終わるまで、集中が途切れない。静かな場面ほど緊張が高い。
2. **負けの原因が自分にあり、次は防げる。** 失敗すると、相手が実際に言った音声と自分の申し送りが並べて示される。「言っていた。自分が変えた」と分かる。運や反射神経ではない。
3. **内容は覚えられないが、聞き方は上達する。** 会話は毎回新しい。しかし「この話し手は最後に条件を足す」といった話し方の型を見抜く力は積み上がる。成長するのはキャラクターではなくプレイヤー自身である。
4. **世界が正確さに応える。** 正しく運んだ言葉で橋が直り、灯籠がともり、霧が晴れて景色が開ける。歪めた言葉は人の間に行き違いを生む。
5. **「分からない」と言える強さ。** 断定して外すより、不明と認めて確かめる方が強い。普通のゲームと逆の勇気が要る。

## 5. 世界観（独自設定。名称は仮称）

### 霧音（きりね）の国

山深い国。この国の霧は墨を溶かし、書かれた文字は一晩で読めなくなる。だから約束も、頼みごとも、証言も、すべて人の口から口へ運ばれる。

言葉を運ぶ役目を**聴き継ぎ**という。聴き継ぎは聞いたことだけを運ぶ。足さず、削らず、変えない。聴き継ぎが言葉を歪めると、人と人の間に霧が濃く立ちこめ、道が閉ざされる。この現象を里の者は**歪み**と呼ぶ。

プレイヤーは見習いの聴き継ぎとして麓の里を出て、霧の上の山城を目指す。

### 見た目と音の方針

- **景色**: 杉木立の参道、苔むした石段、渓流沿いの寺、紅葉の峠、霧の上に浮かぶ山城。
- **霧**: 物語の中心であり、情報の不確かさの象徴でもある。正しく受け取るほど晴れる。
- **光と天候**: 木漏れ日、雨、夕暮れ、月明かり。地域ごとに主となる天候を変える。
- **音**: 静寂を基調にする。風、水、鐘、虫の声。音楽は控えめにし、会話中は環境音を下げて声を際立たせる。成就と歪みの瞬間だけ強い音を使う。
- **画面表示**: 最小限。縦書きと余白を活かし、墨と和紙の質感にする。

### 既存作品との関係

「美しく緊張感のある和風3D」「失敗に厳しい」という方向性は参考にするが、固有の要素は使わない。登場人物、地名、筋書き、音楽、アセット、固有の用語や仕組みの名前はすべて独自に作る。制作段階で、既存作品に似すぎていないかの確認工程を設ける（[10](10-roadmap.md)）。

**画質についての正直な見通し**: 大規模な開発体制で作られた作品と同等の画質を、小規模体制やスマートフォンで実現できるとは主張しない。目指すのは、構図・光・霧・音の設計で成り立つ、統一感のある美しさである（[07](07-unity-architecture.md) §2、[13](13-quality-audit.md) 指摘3）。

## 6. 3D空間が受信の訓練に果たす役割

3D は没入感のためだけに置かない。受信そのものに関わらせる。

| 3D の使い方 | 受信訓練としての意味 |
|---|---|
| 聞いた言葉を持って受け手まで歩く | 景色や他人の声に気を取られても、内容を変えずに保つ |
| 言われた通りに行動する試練 | 「三つ目の灯籠を左。ただし橋が落ちていたら戻れ」を実際に歩いて実行する。判定は行動結果なので客観的 |
| 複数の話し手が別の場所にいる | 誰が何を言ったかを、位置と声で区別する |
| 歩きながら話す相手 | ついて歩きながら聞く。注意が分かれた状態での受信 |
| 環境の出来事 | 鐘、鳥、通行人。重要な一言の近くで起きる（上級のみ） |
| 霧が晴れる | 正確な受信への報酬として、景色そのものを見せる |

## 7. 対象とする人

- 仕事や生活で、話を聞き違えたり早合点したりする癖を直したい人。
- 難しいゲームを、理由の分かる失敗を重ねて乗り越えるのが好きな人。

医療・診断・治療の効果はうたわない。学習効果は現時点で未実証であり、検証計画を [11](11-test-plan.md) §8 に置く。
