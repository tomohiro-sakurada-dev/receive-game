# 11 テスト計画

基準値はすべて仮の値であり、第2段階で実測してから確定する。

## 1. 全体像

| 区分 | 目的 | 節 |
|---|---|---|
| 規則と進行 | 罰の規則が設計どおりに働く | §2 |
| 評価役 | 判定が正しい。特に、誤って罰しない | §3 |
| シナリオ生成 | 出題が公平で、毎回違う | §4 |
| 会話役 | 誘導しない、評価しない、役を保つ | §5 |
| 音声 | 認識と合成の誤りが失敗の原因にならない | §6 |
| 性能・料金・安全 | 目標の範囲に収まる | §7 |
| 学習効果と面白さ | 本当に受信の力が伸び、遊びとして成り立つ | §8 |

## 2. 規則と進行（自動テスト）

中核は Unity に依存しないので、すべて自動で検査できる。

| 対象 | 確かめること |
|---|---|
| 判定の規則表 | 状態と重要度のすべての組み合わせで、A・B・C が設計どおりになる |
| 結果の決定 | 成就、未達、歪みの条件。格の決定 |
| A の成立条件 | 確信が「確実」でない、引用が実在しない、2回目が不一致、のいずれでも A にならない |
| 不明の申告 | 申告した欠落は罰にならず、最重要なら未達になる |
| 縮退した戦い方 | すべて不明、すべて推し量り、で成就にならない |
| 灯火と道行き | 減り方、尽きたときの戻り、やり直しでシナリオが変わる |
| 封印 | 封印が回答より後なら判定が無効になる。封印後は無効化以外の変更ができない |
| 一度きり | 同じシナリオが同じ利用者に二度出ない |
| 無効試合 | 障害時に灯火と進行が元に戻る |
| 状態の流れ | すべての状態から、中断と復帰ができる |
| 読みと表記の正規化 | 数、日付、読み仮名の揺れが同じものとして扱われる |

## 3. 評価役の検定

### 正解集

| 項目 | 内容 |
|---|---|
| 構成 | シナリオ（評価基準票と発話記録）と、それに対する回答の組。各組に、人が情報素片ごとの正しい状態を付ける |
| 回答の種類 | 完全に正しい、言い換えただけ、取り違え、自覚のない欠落、申告した欠落、捏造、確度の過大と過小、正当な不明、判断の分かれる境界例、指示を混入させた回答 |
| 規模 | 最初は数百組。物言いで覆った事例を加えて増やす |
| 正解付け | 2人以上が独立に行い、食い違いは協議して決める。協議しても決まらない組は「境界例」として、A にならないことだけを確かめる |

### 指標と基準

| 指標 | 基準（仮） |
|---|---|
| 誤って A とした割合（正しい回答、または B 以下の回答を A とした） | 1% 未満 |
| A を見逃した割合 | 10% 未満 |
| 言い換えを誤りとした割合 | 2% 未満 |
| 引用が実在しなかった割合 | 監視する。高ければ指示文を直す |
| 同じ入力を繰り返したときの判定の一致 | 95% 以上 |
| 指示を混入させた回答で判定が変わった数 | 0 |

### 運用

- モデル、指示文、規則表のどれかを変えたら、必ず正解集で測り直す。基準を下回る版は使わない。
- 公開後は、物言いの件数、覆った割合、2回の評価が食い違った割合を監視する。

## 4. シナリオ生成の検査

| 対象 | 方法 | 基準（仮） |
|---|---|---|
| 形式 | 生成結果の自動検査（必須項目、読み仮名、禁止語） | 不合格は自動で作り直す |
| 解答可能性 | 検品役が台本だけから情報を取り出し、評価基準票と比べる | 最重要の項目で全員一致 |
| あいまいさ（人による確認） | 検品を通ったシナリオを人が読み、あいまいな項目を数える | ほぼゼロ。見つかったら検品の方法を直す |
| 多様性 | 1,000本を生成し、題材・構造・固有の値の分布と、文の重なりを測る | 偏りがない。同じ利用者の直近の出題と重ならない |
| 罠の比率 | 罠のない会話の割合 | 2〜3割 |
| 難易度 | 設定した難易度と、人の正答率の関係 | 難易度が上がると正答率が下がる |
| 自然さ | 人が読んで（聞いて）採点する | 不自然な誘導や説明口調がない |
| 題材の制限 | 禁止した題材が出ない | 0 |
| 拒否 | AI が生成を断った割合 | 監視する。高ければ題材や指示を直す |
| 独自性 | 既存作品の固有名や設定が出ない | 0 |

## 5. 会話役の検査

| 対象 | 方法 |
|---|---|
| 誘導しない | 多数の聞き返しを与え、重要さを示唆する発言がないかを調べる |
| 評価・助言をしない | 「どう聞けばよいか」と尋ねても、役として受け流す |
| 事実の表を守る | 表にない事実を作らない。知らないことは知らないと言う |
| 誤った復唱の訂正 | 誤った復唱を与え、訂正することを確かめる |
| 役を保つ | 世界の外の話題、指示の上書きの試みを与える |
| 性格の一貫性 | 台本と応答で話し方が変わらない |

## 6. 音声の検査

| 対象 | 方法 | 基準（仮） |
|---|---|---|
| 音声認識の精度 | 試験用の音声（複数の話者・機器・環境）で、文字の誤り率と重要な語の正解率を測る | 静かな環境で重要な語 97% 以上 |
| 音声合成の読み | 日付、数、固有名、同音異義語を含む文を合成し、人と自動検査で読み誤りを数える | 検品後の読み誤りがほぼゼロ |
| 音声の検品 | 意図的に読み誤らせた音声を混ぜ、検査が見つけるかを測る | 見逃しを把握し、語彙表で補う |
| 発話終了の検出 | 言いよどみや長い間を含む発話で、途中で切れた割合を測る | 申し送りでは 0（手動で終えるため）。聞き返しでは低く抑える |
| 反響 | スピーカー使用時に、話し手の声を誤って認識しないか | 既定の方式で 0 |
| 遅延 | 聞き返しから応答の声が出るまでの時間 | 目標時間内 |
| 聞き疲れ | 30分以上の連続試聴 | 不快の報告がない |
| 話す速さ | 0.8〜1.2倍で音質が保たれるか | 聞いて違和感がない |
| 障害 | 音声サービスを止め、代替への切替と無効試合の処理を確かめる | 罰が発生しない |

## 7. 性能・料金・安全

| 対象 | 方法 |
|---|---|
| フレームレート、記憶域、読み込み | 対象機種ごとに計測。目標は [07](07-unity-architecture.md) §3 |
| 発熱と電池 | スマートフォンで30分の連続プレイ |
| 通信の悪条件 | 遅い回線、切断、復帰。試練の途中で切れた場合に罰が発生しない |
| 料金 | 1試練あたりのトークン数、音声の文字数と秒数を記録し、見積もりと比べる |
| 利用量の上限 | 上限を超える要求が止まる |
| 鍵の保護 | アプリと通信内容に鍵が含まれない |
| 正解の保護 | 判定の前に、端末へ評価基準票や正解が送られない |
| 不正な要求 | アプリを装った要求で、指示文の指定や他人のデータの取得ができない |
| 個人情報 | 記録に回答文の全文や個人を特定できる情報が出ない。削除の要求が働く |

## 8. 学習効果と面白さ

### 面白さと公平さ（人による試験）

| 項目 | 方法 | 基準（仮） |
|---|---|---|
| 失敗への納得 | 歪みの直後に「自分の聞き方が原因だと思うか」を尋ねる | 8割以上が納得 |
| 再挑戦の意欲 | 失敗後に続けた割合 | 高い水準を保つ |
| 理不尽の報告 | 自由記述と物言いの内容を分類する | 音声・あいまいさ・誤判定が原因のものを個別に直す |
| 規則の理解 | 未達と歪みの違い、確度の印の意味を説明できるか | 導入を終えた人の大半が説明できる |
| 記憶力ゲームになっていないか | 失敗の内訳。単に量が多くて覚えきれない失敗の割合 | 低い。高ければ情報の量を減らし、構造で難しくする |
| 罠探しになっていないか | 罠のない会話での誤答（疑いすぎ）の割合 | 低い |

### 学習効果

このゲームで受信の力が伸びるかは**未実証**である。次の方法で確かめる。

| 項目 | 内容 |
|---|---|
| ゲーム内での伸び | 同じ難易度での成功率の推移。罠の型ごとの成績 |
| ゲーム外への広がり | 遊ぶ前と、一定期間遊んだ後に、ゲームとは形式の違う聞き取り課題（別の声、別の題材、別の答え方）を行い、比べる |
| 比較の対象 | 可能なら、遊ばなかった人、または別の活動をした人と比べる |
| 自己評価 | 日常で聞き違いや早合点が減ったと感じるか（参考値。客観的な証拠ではない） |

結果が出るまで、能力向上の効果を対外的にうたわない。医療・診断・治療の効果は、結果にかかわらずうたわない。
