# 03 罰システム設計書

## 1. 方針

**厳しいが、理不尽ではない。** この2つを両立させる条件を先に定める。

| 厳しさ | 理不尽でないことの保証 |
|---|---|
| 致命的なミス1回で試練が即失敗する | 何が致命的かは出題前に決まっており、後から変わらない |
| 失敗すると結び灯籠へ戻り、会話は新しくなる | 失敗の根拠として、相手の実際の発言を必ず示す |
| 灯火は増えない | 確信の持てない判定では致命的にしない |
| | 音声認識の誤りと、あいまいな出題は、失敗の理由にしない |
| | 判定に異議を申し立てられる |

## 2. ミスの分類

評価は情報素片ごとに行う。情報素片には出題前に重要度が付いている（最重要・重要・補足）。

### A: 致命的なミス

| 種類 | 例 |
|---|---|
| 取り違え | 「明後日の朝」を「明日の朝」と伝えた。届け先の人物を間違えた |
| 自覚のない欠落 | 「雨なら中止」という条件に触れず、「以上ですべて」と宣言し、問い返しでも「条件はなかった」と答えた |
| 断定の捏造 | 言われていない届け先を、聞いたこととして伝えた |
| 確度の過大 | 相手が「たぶん」と言った内容を、確定した事実として伝えた |
| 意味の反転 | 「行かなくてよい」を「行ってほしい」と伝えた |

A になるのは、**最重要の情報素片**に関わる場合、または捏造・過大が**日時・人物・対象・条件・数量・場所・求められた行動**のいずれかを変える場合である。

### B: 中程度のミス

| 種類 | 例 |
|---|---|
| 重要な情報素片の取り違え・自覚のない欠落 | 理由の説明を落とした |
| 順序の誤り | 手順の2番目と3番目を入れ替えた（結果が変わらない範囲） |
| 条件の一部の不正確 | 「朝のうち」を「午前」とした程度のずれ |
| 確度の過小 | はっきり言われた最重要の内容に「推し量り」の印を付けた |
| 周辺的な捏造 | 相手の気持ちなど、行動に影響しない脚色を事実として述べた |

### C: 軽微なミス

| 種類 | 例 |
|---|---|
| 補足の情報素片の欠落・取り違え | 話のついでに出た天気の話を落とした |
| 細かな表現の忘れ | 言い回しの違い（意味は同じ） |

言い換えはミスではない。意味が同じなら、表現が違っても正しい受信として扱う。

## 3. 「不明の申告」の扱い

仕様には「重要な条件を完全に聞き漏らすのは致命的」と「不明点を正直に申告すれば罰なし」の両方がある。両立のために、欠落を2つに分ける（**要承認: [00](00-overview.md) Q3**）。

| 状況 | 扱い | 理由 |
|---|---|---|
| 会話で実際に言われていない事柄を「不明」とした | **正解**。加点 | 不明を不明と認識できている |
| 言われた内容を落とし、落としたことに気づいていない | **A（最重要の場合）** | 欠けた情報を完全なものとして渡した。現実で最も害が大きい |
| 言われた内容を落としたが、「条件があったが聞き取れなかった」と申告した | **罰なし**。ただし最重要なら結果は**未達** | 誤った情報は渡していない。しかし務めは果たせていない |

- 未達は罰ではない。灯火は減らず、結び灯籠にも戻らない。その場で別の会話に挑み直す。
- すべてを「不明」とする戦い方では、決して成就にならない。
- すべてに「推し量り」の印を付ける戦い方は、確度の過小（B）が重なり灯火が尽きる。
- 最も良い行動は、会話中に間合いを使って確かめることである。

## 4. ペナルティ

| 分類 | ペナルティ |
|---|---|
| A | 試練は**即失敗（歪み）**。他の項目がすべて正しくても覆らない。結び灯籠へ戻り、道行きをやり直す |
| B | **追い稽古**（同じ能力を試す短い追加課題）に挑む。成功すれば灯火は減らない。失敗、または辞退すると灯火が1つ減る |
| C | 減点。成就の格が下がる（明鏡→澄） |
| 不明の正直な申告 | 罰なし |
| 適切な確認 | 加点。格の判定で有利になる |

- 灯火が尽きると、道行きを結び灯籠からやり直す。
- B が1つでもあれば、格は濁になる。
- 「即失敗」とは、その判定が出た時点で他の採点に関係なく試練の失敗が確定することを指す。判定は申し送りと問い返しがすべて終わった後に1回行う（待ち時間を1回にまとめるため）。演出では、申し送りの文を順にたどり、歪みのあった一文で場面が止まる。

## 5. 重要度の事前確定

**重要な情報は、プレイヤーの回答を見る前に確定させる。後付けはしない。**

| 時点 | 確定すること |
|---|---|
| シナリオ生成時 | すべての情報素片の重要度、正解、確度の区分、問い返しの一式 |
| 検品時（プレイヤーに出す前） | 別のAIが台本だけを読んで情報を取り出し、評価基準票と一致するかを確かめる。一致しない項目はあいまいと見なし、シナリオを作り直す |
| 会話終了時（回答の前） | 実際に発話された内容と評価基準票を突き合わせる。発話の裏付けがない項目は無効にする。この時点の評価基準票を**封印**する（内容の要約値と時刻を記録） |
| 判定時 | 封印した評価基準票だけを使う。評価役は重要度を変更できない |

封印の後に変えられるのは、項目を**無効にする方向だけ**である（プレイヤーに有利な方向）。重要度を上げることや、項目を足すことはできない。

## 6. 理不尽を防ぐ規則

| No. | 規則 |
|---|---|
| F1 | **証拠なしに罰しない。** すべてのミス判定は、相手の発言の逐語引用と、プレイヤーの文の逐語引用を伴う。引用が実際の記録に存在するかをプログラムで照合し、存在しない引用に基づく判定は捨てる |
| F2 | **疑わしきは軽く。** A の判定は、独立した2回の評価がともに「確実」とした場合だけ成立する。一致しなければ B 以下に下げる |
| F3 | **音声認識の誤りで罰しない。** 評価対象は、プレイヤーが画面で確かめて確定した文だけである。認識の途中経過は評価に使わない |
| F4 | **音声合成の誤りで罰しない。** 最重要の情報素片は、合成した音声を認識し直して、意図した読みと一致することを事前に確かめる。一致しない音声は出さない |
| F5 | **あいまいな出題で罰しない。** 検品であいまいと判定された項目は出題しない。会話後の突き合わせで裏付けが弱い項目は無効にする |
| F6 | **聞き分けにくい音で罰しない。** 最重要の人名・地名・数は、音の似たもの同士を同じ会話に置かない。似た音による引っかけは作らない |
| F7 | **初見の罠で罰しない。** 新しい型の罠は、稽古か導入で一度体験させてから本番に出す |
| F8 | **表記や読みの揺れで罰しない。** 「七日」と「なのか」、「明後日」と「あさって」は同じものとして扱う |
| F9 | **異議を受け付ける。** 物言い（[05](05-ai-evaluation.md) §7）で覆れば、失ったものをすべて戻す |
| F10 | **障害で罰しない。** 通信・音声・AIの障害で試練が成立しなかった場合は、無効試合とし、灯火も進行も元に戻す |

## 7. 判定の流れ

1. 評価役が、情報素片ごとに状態を判定する（一致、取り違え、自覚のない欠落、申告された欠落、捏造、確度の過大・過小、正当な不明）。
2. **プログラムの規則表**が、状態と重要度から A・B・C を決める。AI は罰を決めない。
3. A の候補があれば、2回目の独立した評価を行う。2回目は「プレイヤーの文が正しいと読める解釈はないか」を探す立場で行う。
4. 両方が確実とした A だけを確定する。
5. 結果（成就・未達・歪み）と格を決める。

## 8. 失敗の後

歪みの後に、次を必ず示す。

- 相手が実際に言ったこと（該当箇所の音声を聞き直せる）
- プレイヤーが伝えたこと
- ミスの種類（取り違え、補完、早合点、聞き漏らし、確度の誤り）
- どの時点で防げたか（例: 「話の終わりに条件が足されていました」）

人格や能力を責める表現は使わない。事実だけを静かに示す。助言は試練の後だけに出し、会話中には一切出さない。

## 9. 調整の対象（試作で決める値）

灯火の数、間合いの回数、道行きの長さ、A を成立させる確信の水準、追い稽古の長さ。これらは仮の値であり、遊んで確かめてから決める。調整しても変えないもの: A は即失敗、重要度は事前確定、証拠の提示。
